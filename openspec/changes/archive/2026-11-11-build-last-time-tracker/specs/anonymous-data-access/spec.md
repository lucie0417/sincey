# Spec Delta

## Purpose

讓使用者不必註冊或登入即可保存私人生活紀錄，並透過瀏覽器中的匿名存取憑證隔離伺服器資料。清楚界定原瀏覽器存取、資料持久性及連線失敗時的行為，避免把匿名儲存誤認為帳號同步。

## ADDED Requirements

### Requirement: 匿名初始化與持久保存
系統 SHALL 在首次連線建立匿名資料空間並於瀏覽器保存存取憑證；事件存在伺服器，重新整理後仍可讀取。不存在登入、帳號找回或自動跨裝置同步功能。

#### Scenario: 重新整理
- **WHEN** 使用者建立事件後以同一瀏覽器重新整理
- **THEN** 系統載入同一份已保存事件

#### Scenario: 遺失憑證
- **WHEN** 使用者清除瀏覽器資料或改用另一瀏覽器
- **THEN** 系統建立新的空資料空間，無法自動取得原資料，介面說明可用備份還原

### Requirement: 資料隔離
系統 MUST 依有效匿名憑證限定所有事件讀取、更新、刪除、匯出與匯入；事件 ID 本身不得授權資料存取，回應與備份不得暴露存取憑證。

#### Scenario: 存取他人事件
- **WHEN** 使用者以自己的憑證請求另一資料空間的事件 ID
- **THEN** 系統拒絕請求且不洩漏或修改該事件

#### Scenario: 無有效憑證
- **WHEN** 請求沒有有效憑證而直接操作事件或備份
- **THEN** 系統拒絕請求且不回傳任何私人事件

### Requirement: 連線與失敗復原
系統 SHALL 要求連線才能讀寫，載入與送出時顯示狀態；失敗保留未送出的表單與搜尋內容並提供重試，且不得將未確認成功的操作顯示為已保存。

#### Scenario: 儲存失敗
- **WHEN** 使用者送出表單但網路中斷
- **THEN** 顯示失敗與重試入口，保留輸入，不顯示成功

#### Scenario: 讀取失敗
- **WHEN** 初次載入事件失敗
- **THEN** 顯示錯誤與重試入口，不把錯誤誤顯示為沒有事件
