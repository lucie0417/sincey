# 專案技術棧檢查

## 規則來源

讀取適用於目標目錄的 AGENTS.md。
技術棧清單以 AGENTS.md 為準，不在此檔案重複維護。

## 工作流程

1. 讀取與任務相關的套件清單、lockfile、執行環境版本檔
   及建置設定；不存在的檔案不需建立。
2. 判斷本次工作是否引入新技術、新增依賴、
   更換工具或改變主要版本。
3. 在 AGENTS.md 允許的技術範圍內選擇實作方式，
   優先沿用專案現有模式。
4. 若需要例外，說明違反哪一條規則、原因及最小替代方案。
   未取得同意前，不執行需要例外的變更。
5. 檢查本次差異中的依賴、import、設定與 lockfile，
   確認沒有引入未核准的工具。
6. 執行與改動相關且專案已設定的檢查；
   不要為了檢查而自行安裝新工具。

## 結果回報

簡短說明：
- 是否符合技術棧規則。
- 新增或修改了哪些依賴。
- 有哪些例外已取得同意。
- 實際執行的檢查，以及尚未驗證的部分。
