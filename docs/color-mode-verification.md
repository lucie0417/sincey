## 行為驗證

`tests/color-mode.spec.ts` 涵蓋：

- 裝置系統淺色與深色下，首頁、新增、編輯、備份頁直接載入皆為淺色。
- 雙向切換立即改變實際背景、根元素的原生控制項配色提示與 theme-color。
- 切換系統外觀不改變網站模式。
- 站內換頁維持模式，重新整理及新分頁回到淺色，原分頁不受影響。
- 不增加偏好 storage、cookie 或備份欄位，切換不觸發記事讀寫請求。
- 觸控、滑鼠、鍵盤均可操作，資料載入中及錯誤頁仍可切換；320px 頁首入口可見且無水平溢出。
- 搜尋、未送出表單、事件資料及原本五秒復原期限不因切換而重設。
- 深色下完成實際 API／PostgreSQL 的新增、日期更新、復原、編輯、匯出、匯入與刪除流程。
