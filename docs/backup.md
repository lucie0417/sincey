# 備份與還原

在「備份與還原」點下載備份，取得 JSON 檔，內容如下：

```json
{
  "version": 1,
  "exportedAt": "2026-01-01T00:00:00.000Z",
  "events": [{ "title": "洗牙", "lastDoneOn": null, "note": "帶健保卡" }]
}
```

不包含事件 ID、內部使用者 ID、revision 或憑證。相同標題各自保存，備註保留換行。檔案含私人生活資訊，請妥善保管。

全部記事的格式化備份總量上限 2 MB；超過時新增或更新不會儲存，請依畫面訊息縮減內容。這讓完整匯出的檔案仍可被還原。

還原步驟：

1. 建議先匯出目前資料留底。
2. 選取 JSON 檔，系統驗證版本、完整欄位及日期（不可未來），上限 2 MB、5,000 筆。
3. 核對目前與備份筆數；取消不變更資料。
4. 點「確定完整取代」，成功後所有舊事件被取代，沒有合併或去重；零筆備份會清空目前事件。

伺服器在資料庫交易內完成刪除與新增，任一步失敗會回滾。若連線中斷，可能是回應遺失，請先返回首頁確認，不要直接重複取代。匯入錯誤格式不會改動現有資料。

新瀏覽器也可照此還原，事件會獲得新 ID 並屬於新的匿名空間。這不會取得原瀏覽器的存取憑證，也不會建立同步連結。
